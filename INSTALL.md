# TradeMind AI - Extension Install Guide

## Chrome / Edge (Chromium)

1. Open `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select the `/home/workspace/TradeMind/extension/` folder
5. Click the puzzle piece icon in toolbar → TradeMind AI
6. Pin it for easy access!

## Firefox

1. Open `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on**
3. Navigate to `/home/workspace/TradeMind/extension/manifest.json`
4. Done! Look for the TradeMind icon in your toolbar

## After Installation

Click the TradeMind icon in your browser toolbar to:
- 📊 View real-time accuracy stats
- 📈 See recent trading signals
- 🛒 Place paper trades via Dhan
- 🔄 Auto-refresh every 60 seconds
